# OLED asset provenance

These binary fonts and 128x64 monochrome backgrounds use the exact format expected by the legacy Argon40 OLED implementation and the Rust port. They were retrieved from the paths used by Argon40's official installer at `https://download.argon40.com/oled/` on 2026-08-11.

They are data files, not executable code. No license grant was present in this repository or in the downloaded installer; downstream redistributors should confirm their right to redistribute the vendor artwork and font data. The installer embeds these files so an OLED-capable installation does not need Python or a network download.
